# Практическая работа № 4. Регрессионная модель

## Цель работы
Построить модель линейной регрессии, проверить мультиколлинеарность признаков, сравнить модели и оценить качество предсказаний.

## Датасет
California Housing Dataset — 20 640 наблюдений, 8 числовых признаков и целевая переменная `MedHouseVal`.

## Используемые технологии
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Statsmodels
- Jupyter Notebook

## Выполненные задачи
1. Загрузка и исследование данных.
2. Разделение на обучающую и тестовую выборки.
3. Обучение базовой линейной регрессии.
4. Анализ корреляций и расчёт VIF.
5. Отбор признаков и обучение сокращённой модели.
6. Сравнение MAE, RMSE и R².
7. Анализ остатков и визуализация предсказаний.

## Структура проекта
- `data/` — исходный датасет.
- `notebooks/` — анализ и обучение моделей.
- `results/` — графики и результаты сравнения.
- `requirements.txt` — зависимости проекта.

## Запуск
Установить зависимости командой `pip install -r requirements.txt`, затем открыть `notebooks/regression_analysis.ipynb` в VS Code и выполнить ячейки по порядку.
